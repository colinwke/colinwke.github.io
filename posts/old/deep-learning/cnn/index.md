# cnn


先看一个DNN, CNN, RNN的比较

|      | 深度                 | 输入   | 参数         | 输出   |
| ---- | -------------------- | ------ | ------------ | ------ |
| DNN  | 神经元堆叠层数       | 向量   | 连接         | 向量   |
| RNN  | 序列长度             | 向量   | 连接         | 向量   |
| CNN  | 一组操作(卷积, 池化) | 特征图 | 连接, 卷积核 | 特征图 |



**Q**:CNN中原图和卷积生成的特征图的位置是对应的吗?

**A**: 是对应的.

因为卷积(或池化)生成的特征图一直都是一一对应(这也是局部关联的实现).

如果最后提取的特征图为4个神经元的正方形, 那么这四个神经元是对应的,

如果最后提取的特征图为一个神经元的输出, 那么, 这个神经元的信息已经包含了整张图片的信息.
